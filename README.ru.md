### Шаг 2 — Установка

<details open>
<summary><b>🪟 Windows</b></summary>

1. Скачайте `.zip` для Windows (например, `G-Labs-Voice-Studio-v2.0.2-win.zip`) и **распакуйте** в любую папку — на диске нужно не менее 10 ГБ свободного места (модели ИИ, которые скачиваются позже, занимают несколько ГБ).

## Первый запуск

1. **Откройте приложение и выберите язык интерфейса** на приветственном экране (его можно сменить позже в настройках).
2. **Войдите через Google** — Настройки ⚙️ → **Лицензионные аккаунты** → **Войти через Google**.
3. **Скачайте голосовую модель** — откройте вкладку **Модели** (или следуйте подсказке приложения) и скачайте голосовую модель ИИ (несколько ГБ, один раз). Модели распознавания речи скачиваются отдельно при первом использовании.
4. **Откройте вкладку Чтение текста**, выберите **язык вывода** и голос из библиотеки (30 встроенных голосов).
5. Вставьте текст → **Добавить в таблицу** → **Запустить**. Прослушайте каждую строку, затем нажмите **Экспорт аудио**, чтобы сохранить файл (по умолчанию вместе с субтитрами `.srt`).

## Возможности

<p align="center">

- **Работает на вашем компьютере** — после загрузки моделей генерация голоса и расшифровка выполняются локально (NVIDIA GPU, Apple Metal или CPU); ваше аудио и текст не отправляются на сервер. Только вкладка перевода отправляет текст субтитров выбранному вами ИИ-провайдеру.
- **Клонирование голоса** — по образцу длиной 5–10 секунд озвучивайте любой текст именно этим голосом.
- **Дизайн голоса** — создайте новый голос по полу, возрасту, высоте, стилю и акценту; образец не нужен.
- **600+ языков вывода** — вьетнамский, английский, китайский, японский, корейский, французский, немецкий, испанский и многие другие.
- **Многоголосый диалог** — сценарии вида `<Имя>: реплика`, у каждого персонажа свой голос и скорость.
- **Извлечение субтитров** — расшифровка MP3, WAV, M4A, FLAC, MP4, MOV…; экспорт в TXT или SRT с таймингом по словам.
- **Перевод субтитров с ИИ** *(тариф Studio)* — перевод или вычитка `.srt`, `.vtt`, `.ass`, `.sbv`, `.txt`; тайминги и число строк остаются точно такими же.
- **Библиотека голосов** — 30 встроенных голосов, сохранение своих, закрепление ⭐ избранных, резервная копия/восстановление в файл `.vcp`.
- **Тонкая настройка звука** — 6 режимов обработки, выравнивание громкости, 13 тегов эмоций и словарь произношения, который запоминает, как читать `100%`, `25°C`, `m²`.
- **Гибкий экспорт** — WAV или MP3, один общий файл или по файлу на предложение, с `.srt`; отдельную строку можно скачать кнопкой ⬇.
- **Очередь рендеринга** *(тариф Studio)* — поставьте в очередь несколько сценариев; приложение выполнит их по одному и сохранит файлы.
- **Webhook API** *(тариф Studio)* — локальный REST-сервер для n8n, Make, Zapier, Python/cURL или ИИ-агентов.
- **Подстраивается под железо** — несовместимая видеокарта переключается на CPU с понятным уведомлением; память GPU освобождается автоматически при простое.
- **9 языков интерфейса** — Tiếng Việt, English, Português, Türkçe, 简体中文, हिन्दी, বাংলা, اردو, Русский.

## Страницы

Страницы находятся на левой боковой панели. Три голосовые страницы (Клон голоса, Чтение текста, Групповой диалог) работают одинаково: выберите **язык вывода** → вставьте текст или **Импорт** (`.txt`, `.srt`) → **Добавить в таблицу** (приложение делит текст на предложения по выбранному параметру «Режим разделения» с предпросмотром числа строк) → **Запустить** → прослушайте → **Экспорт аудио**.

### 🔊 Клон голоса

Нажмите **Выбрать...**, чтобы загрузить аудиообразец (чистый голос, мало шума), затем **перетащите подсвеченную рамку на волновой форме**, чтобы точно выбрать фрагмент 3–30 секунд — при отпускании края притягиваются к ближайшей тишине; у файлов длиннее 5 минут / 50 МБ берутся первые 30 секунд. Поле *Образец текста* **обязательно** и должно точно совпадать со словами образца (включая пунктуацию и орфографию); **✨ Подсказка ИИ** расшифрует его за вас, но проверьте перед генерацией. После клонирования приложение предложит прослушать голос и сохранить его в библиотеку одним щелчком.

### 🎛️ Чтение текста

Выберите голос из библиотеки или откройте **Дизайн голоса**, чтобы создать новый по *полу, возрасту, высоте, стилю, акценту*. Понравился созданный голос? Выделите его строку в таблице → **Сохранить** в библиотеку для повторного использования. Режим разбиения **Умное объединение** объединяет короткие предложения в плавные строки до лимита символов, но всегда разрывает на конце предложения. Кнопка **Теги эмоций** позволяет найти теги и вставить их в позицию курсора.

### 💬 Групповой диалог

Напишите сценарий с несколькими персонажами — подходит для подкастов, аудиоспектаклей и интервью:

```
<Ведущий>: Добро пожаловать.
<Mai>: Привет, очень рада быть на передаче.
<Minh>: Я тоже — о чём сегодня поговорим?
```

Имя персонажа ставится в `< >` в начале строки (`:` можно не ставить, регистр имён не важен). Нажмите **Пример диалога**, чтобы увидеть пример, затем **Разобрать диалог** — откроется панель **Назначение голосов**, где каждому персонажу назначается голос из библиотеки и собственный ползунок **скорости** (0.5× → 2×).

### 📝 Извлечь субтитры

Выберите аудио/видеофайл (MP3, WAV, M4A, FLAC, MP4, MOV…), язык речи и модель распознавания (Tiny → Large v3, для каждой указан нужный объём VRAM) и запустите. Строки субтитров строятся по меткам времени слов и разрываются на реальных паузах / концах предложений / лимите символов; измените поля *макс. символов, макс. секунд, порог паузы* — и таблица сразу обновится, без повторного распознавания. Редактируйте прямо в таблице и экспортируйте `.txt` или `.srt`.

### 🌐 Перевод *(тариф Studio)*

Переводите субтитры на другой язык или вычитывайте орфографию и разбиение строк — **меняется только текст; тайминги и число строк остаются прежними**.

1. Однократная настройка в **Модели → LLM**: выберите **9Router** (шлюз на вашем компьютере — укажите адрес и API-ключ), **Claude CLI**, **Antigravity** (`agy`) или **Codex CLI** (установите и войдите). В каждой строке есть кнопка **Инструкция** с командой установки; после установки нажмите **Обновить список** — приложение обнаружит провайдера и покажет его модели.
2. **Импорт**: `.srt`, `.vtt`, `.ass`, `.sbv`, `.txt` — или **Из субтитров**. В `.txt` нет таймингов, поэтому приложение назначит временные и сообщит об этом.
3. Рекомендуется: **Привести текст в порядок** склеивает фрагменты, разорванные посреди предложения (часто бывает в субтитрах из видеоредакторов), с предпросмотром вроде *«120 строк → 68 строк»* перед применением.
4. Выберите **Перевод**, **Редактура** или **Перевод + Редактура**, целевой язык и модель, затем **Запустить**.
5. **Таблица единообразия** фиксирует имена, термины и формы обращения для всего файла и отправляется с каждым фрагментом; её можно редактировать и при желании остановиться для проверки перед переводом.
6. Проверьте столбец **Результат** (строки, пропущенные ИИ, помечены ⚠ и сохраняют исходный текст), выберите **SRT / VTT / TXT** и нажмите **Экспорт**.

### 📚 Модели

По строке на каждую модель с размером и статусом: голосовая модель ИИ и модели распознавания (Tiny, Base, Small, Turbo, Large v3). Скачивайте только нужное и меняйте **папку моделей** (например, на диск D, чтобы разгрузить C — скопируйте старую папку моделей или дайте приложению скачать заново). Здесь же настраиваются **LLM**-провайдер для перевода и таймер **Автоосвобождение VRAM**.

### 🗒 Очередь рендеринга *(тариф Studio)*

Вместо того чтобы генерировать сценарий и экспортировать вручную, нажмите **Добавить в очередь** — текущий сценарий + голос + настройки сохранятся как задание **со своим именем и папкой вывода**. **Запустить очередь** — и приложение выполнит задания по очереди, сохранив файлы. У каждого задания видно `X/N предложений`, так что понятно, где не хватает строк из-за ошибок; **Загрузить снова** возвращает задание во вкладку для исправления (ошибочные строки помечены ❌). Очередь сохраняется после закрытия и повторного открытия приложения.

### 🔗 Webhook API *(тариф Studio)*

Локальный REST-сервер, чтобы n8n, Make, Zapier, Python/cURL или ИИ-агенты генерировали голос автоматически. По умолчанию `127.0.0.1:8766` (только этот компьютер), с API-ключом, полем полного **URL** с кнопкой копирования, автозапуском вместе с приложением и журналом запросов в реальном времени. Смените IP на `0.0.0.0` / IP в локальной сети, чтобы другие устройства могли обращаться — тогда API-ключ передаётся по незашифрованному HTTP. Полная схема: [`docs/WEBHOOK_INTEGRATION.en.md`](docs/WEBHOOK_INTEGRATION.en.md).

## Советы

<details>
<summary><b>Мастеринг звука — 6 режимов обработки</b></summary>

В разделе **Мастеринг звука** трёх голосовых вкладок (измените в одной — остальные подстроятся):

- 📻 **Радио** *(по умолчанию)* — стандарт радио/подкаста, тёплый, плотно сжатый.
- 🎬 **Кино** — просторная реверберация, мягкая компрессия.
- 🎙️ **Подкаст** — близкий микрофон, сильная компрессия, без реверберации.
- ☀️ **Тёплый** — усиленные нижние средние, уютное звучание.
- ✨ **Яркий** — чёткие верха, воздушность.
- 🔇 **Чистый** — выход модели без изменений.

**Выровнять громкость между фразами** выравнивает по воспринимаемой громкости (RMS) — больше никаких громких и тихих строк. Чтобы получить необработанный выход модели, выберите **Чистый** и снимите этот флажок.

</details>

<details>
<summary><b>Теги эмоций</b></summary>

Впишите тег в текст (с квадратными скобками; отдельно или посреди предложения, например `Как смешно [laughter] не могу остановиться.`) — голос издаст соответствующий звук вместо чтения слова. Запоминать не нужно: кнопка **Теги эмоций** позволяет найти и вставить тег.

| Тег | Звук |
|---|---|
| `[laughter]` | Смех |
| `[sigh]` | Вздох |
| `[confirmation-en]` | Согласие — «мм-хм» |
| `[question-en]` · `[question-ah]` · `[question-oh]` · `[question-ei]` · `[question-yi]` | Вопросительная интонация |
| `[surprise-ah]` · `[surprise-oh]` · `[surprise-wa]` · `[surprise-yo]` | Удивление |
| `[dissatisfaction-hnn]` | Недовольство — «хнн» |

Выразительность зависит от языка и голоса — сначала попробуйте на коротком предложении.

</details>

<details>
<summary><b>Словарь произношения</b></summary>

В тексте есть `%`, `$`, `°C`, `m²`, названия брендов…? Нажмите **Настроить произношение** перед генерацией: приложение спросит, как читать каждый символ/слово, вы один раз вводите вариант (например, `%` → `процентов`), и оно запомнит его для каждого языка вывода.

</details>

<details>
<summary><b>Скорость и субтитры при экспорте</b></summary>

- **Скорость чтения** находится в разделе *Дополнительные настройки*; элемент **Скорость** в плеере позволяет слушать быстрее/медленнее, а экспортированный файл сохраняет эту скорость без искажения высоты тона.
- **Также экспортировать субтитры** записывает рядом с аудио `.srt` с тем же именем; тайминги берутся из реальной длительности каждого предложения после изменения скорости.
- **Подгонять речь под тайминг субтитров**: если сценарий импортирован из `.srt`, каждая строка ускоряется (максимум 1.8×), чтобы уложиться в свой интервал, — но никогда не замедляется.

</details>

<details>
<summary><b>Автоматическое освобождение памяти</b></summary>

Если приложение какое-то время простаивает (по умолчанию 5 минут), модель ИИ выгружается из VRAM/RAM, чтобы разгрузить компьютер; при следующем действии она загрузится снова. Время можно изменить или отключить функцию в **Модели → Автоосвобождение VRAM**.

</details>

## Системные требования

|   | Минимум | Рекомендуется |
|---|---|---|
| **Операционная система** | Windows 10 (64-бит), macOS 12 на Apple Silicon | Windows 11, macOS 13 или новее |
| **ОЗУ** | 8 ГБ | 16 ГБ и больше |
| **Диск** | 10 ГБ свободно (модели + кэш) | 20 ГБ и больше, SSD |
| **GPU** | Необязательно — работает на CPU | NVIDIA RTX 20-й серии или новее, 8 ГБ VRAM · Mac использует Metal |
| **Сеть** | Интернет для входа/проверки лицензии и загрузки моделей | |

- **Windows:** для ускорения на GPU нужна видеокарта NVIDIA **RTX 20-й серии или новее** (compute capability ≥ 7.0) и драйвер с поддержкой CUDA 12.8. Более старые карты, например GTX 10-й серии, определяются автоматически и работают на CPU.
- **macOS:** только **Apple Silicon** (M1/M2/M3/M4…), ускорение через Metal.
- Режим CPU примерно в 5–10 раз медленнее GPU, но для коротких озвучек вполне годится.

## Устранение неполадок

**Первый запуск очень долгий, заставка не двигается** — Windows/macOS выполняет первую проверку безопасности; подождите 30–60 секунд, не закрывайте. Дальше запуск быстрее.

**Windows останавливается на «Система Windows защитила ваш компьютер»** — нажмите **Подробнее → Выполнить в любом случае**. Приложение не подписано сертификатом Microsoft; это не вирус.

**macOS пишет, что приложение повреждено / не открывается** — оно не нотаризовано Apple. В первый раз щёлкните правой кнопкой → **Открыть** или выполните `xattr -dr com.apple.quarantine "/Applications/G-Labs Voice Studio.app"`.

**Уведомление о переключении на CPU** — ваша видеокарта несовместима (например, GTX 10-й серии). Всё продолжает работать, только медленнее; для скорости нужна NVIDIA RTX 20-й серии или новее либо Mac на Apple Silicon.

**Генерируется только 1 строка за раз** — у вас пробная версия. Купите тариф Studio для неограниченного числа строк.

**Произошёл выход с сообщением о входе на другом устройстве** — один аккаунт работает на одном компьютере одновременно; войдите снова на том компьютере, которым хотите пользоваться.

**Клонированный голос произносит не те слова / «уплывает»** — *Образец текста* должен точно совпадать со словами образца; выберите чистый образец с минимумом шума.

**Спецсимволы читаются неправильно (`100%`, `25°C`…)** — добавьте их произношение в **Настроить произношение**.

**Диск C забит моделями** — смените папку моделей в **Модели**, затем скопируйте туда старую папку или дайте приложению скачать заново.

**Во вкладке Перевод нет моделей для выбора** — установите LLM-провайдера (9Router, Claude CLI, Antigravity, Codex) и войдите в него по кнопке **Инструкция**, затем нажмите **Обновить список**.

**Нужны подробности об ошибке** — нажмите **Подробные логи** на боковой панели.
